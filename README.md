# Yellow River dissolved oxygen study

Data and analysis code for *Dissolved oxygen responses to heatwave–high-flow extremes in the Yellow River Basin: Roles of reference conditions and observational support*. This package accompanies the Supplementary Information dated 17 November 2026 and uses the 11 November 2026 analysis batch. Dissolved oxygen is abbreviated DO.

## Original data and source inputs

| Path | Contents |
| --- | --- |
| [Data/WaterQuality_data/WQ_data_YR](Data/WaterQuality_data/WQ_data_YR/) | Original timestamp-level water-quality CSVs for the 66 study stations. Station names and source fields are preserved as received. |
| [Data/Hydrology_data/Hy_data_YR](Data/Hydrology_data/Hy_data_YR/) | Original hydrology workbooks for 42 gauges. The workbooks contain daily water levels, discharge and sediment records. |
| [Data/Meteorology_data/2021-2025](Data/Meteorology_data/2021-2025/) | Archived Earth Engine station extracts in `M_V1` and `B_V1`, including meteorology, vegetation and land-cover inputs. The station mapping selects the 66 study stations when assembling the daily input. |
| [Data/Meteorology_data/1991-2020/YR](Data/Meteorology_data/1991-2020/YR/) | Archived reference-period temperature series for the 66 station locations. |
| [Data/GIS](Data/GIS/) | Shapefile layers used by map scripts. Keep each shapefile and its companion files together. |
| [Config](Config/) | Earth Engine station lists and the study mapping of 66 water-quality stations to 42 gauges. |

Original filenames, encodings and data values are preserved. The Earth Engine inputs are archived station extracts of ERA5-Land, MODIS and Dynamic World. Consult the data providers' terms for redistribution of their files.

## Supplementary data

The [supplementary data guide](Supplementary_Data/README.md) describes Data S1–S9 and the datasets supporting Tables S4 and S22b. The [index](Supplementary_Data/file_index.csv) lists each CSV by topic, filename, contents and row count.

- [S8 daily DO provenance](Supplementary_Data/S8/daily_DO_observation_provenance.csv) records raw daily, quality-controlled and completed DO. Use `Site_ID` and `Date` to identify records and `DO_Source` to check observation provenance. This CSV contains 120,516 station-days. The original timestamp-level measurements are in the water-quality input folder.
- [S7 event membership](Supplementary_Data/S7/coverage_population_event_membership.csv) uses `Site_ID` and `Event_ID` to identify the 2,548 site–event records and their observation-coverage groups.
- [S4 discharge support](Supplementary_Data/TableS4_Q_Support/) contains 76,692 gauge-days and all 936 basic high-flow episodes. Use `Hydro_Site_ID` and `Date` for daily records. `Basic_Episode_ID` links high-flow days to the episode catalogue.

## Running the scripts

Run commands from this package's root and preserve the folder layout. Start in a working copy because some scripts write to their default output paths. Those paths include processed `Data/` subdirectories, `Result/` and `V/`. The package carries original inputs and the supplementary CSVs. Quality-controlled tables, merged inputs, completed DO series, model checkpoints, analysis outputs and rendered figures are generated by the workflow. The Figure 1b slide template is a script input. The S5 audit PDF panels are separate from the CSVs.

Start with the archived climate extracts and prepare the water-quality and hydrology data.

```text
python Code/01_Data_integration/01_Meteorology_ecology/assemble_meteo.py
python Code/01_Data_integration/01_Meteorology_ecology/normalize_precipitation.py
python Code/01_Data_integration/02_Water_quality_QC/1.WQ_Data_P.py
python Code/01_Data_integration/03_Hydrological_QC/2.Hy_Data_P.py
python Code/01_Data_integration/04_Spatial_matching_and_merge/4.WQ_Hy_M_EVI_Land_Data.py
```

From the merged data, run `ED_N.py` for the original-data event branch, then `Lstm_Y.py` and `LSTM_V1.py` for DO reconstruction. Run `ED_F.py` on the completed series, followed by `decrease.py`, `recovery.py` and `compare_event_do_responses.py` for event responses and the primary models. The [script catalogue](Code/SCRIPT_GUIDE.md) lists exact paths, dependencies, and entry points for the sensitivity analyses, SHAP and figures. Continuous-gap validation uses the checkpoint, scalers and manifest generated by the model training script. Comparisons against archived predictions require the matching model and prediction outputs.

The recorded analysis environment used Python 3.9.21, NumPy 1.26.4, pandas 2.3.0, SciPy 1.13.1, statsmodels 0.14.4, scikit-learn 1.0.2, joblib 1.4.2 and PyTorch 2.5.1 on CPU. Water-data preparation uses openpyxl, pypinyin and chardet. Plotting uses Matplotlib, seaborn and Pillow, with GeoPandas and Fiona for maps. The tree-model scripts use XGBoost, scikit-optimize and SHAP. The optional Figure 1b export uses Node.js, `@oai/artifact-tool` and `sharp`.

The archived station extracts allow the local workflow to start without Earth Engine authentication. To fetch new extracts, configure `GEE_PROJECT` in the download scripts to use an Earth Engine project you can access and authenticate with your own account.
